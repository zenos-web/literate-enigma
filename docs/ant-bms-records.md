# ANT BMS：完整电池页面与记录统计

基于上游已合入的 ANT 实时读取和电池卡片，补齐开发版本的统计与记录功能。接入继续由 ANTBMSController 管理，主接收界面只通知接收会话开始与停止。

## 功能

| 页面 | 行为 |
| --- | --- |
| 实时电池与详情 | 沿用已有 ANT FFE0/FFE1 读取、CRC 校验、五秒新鲜度、设备记忆/重连、电量/总压/电流/功率/温度/压差及详细参数。 |
| 卡片显示 | 沿用六字段选择与排序、四角位置、三种字号、背景透明度、快捷布局与实时/示例预览，手机与九号五寸/七寸使用同一卡片。 |
| 本次统计 | 开启 BMS 后启动接收会话自动记录；也可在 BMS 页面手动开始或结束。统计有效采样时长、帧数、起止电量、全程电压范围、绝对峰值电流/功率、最高温度和最大压差。 |
| 电压趋势 | 最近 120 个五秒区间保存最低、最高与最新值，保留短时压降；断线处分段。支持轻点、横向拖动和 VoiceOver 逐区间查看。 |
| 历史记录 | 本机最多保存 20 次，每 15 秒保存片段；停止接收或关闭 BMS 时完成记录，更换 BMS 时分开保存。区分记录中、正常结束和未正常结束的片段。 |
| 筛选与删除 | 按保存的车辆/仪表名称、BMS 设备、今天/近七天/近三十天及记录状态筛选。非活动记录可在确认后删除。 |
| 导出 | 预览、复制和分享 JSON 完整统计或电压 CSV。CSV 只含保留的趋势区间，使用固定小数点和 CRLF，并标明旧版抽样及断线分段。 |

断线间隔、重复回调、过时样本和时钟倒退不会累计有效采样时间。所有统计来自校验有效的实时帧，示例数据只在布局预览使用，不进入记录。记录不计算里程或预计续航。

上游目前没有开发分支的整套车辆配置管理器，因此默认以启动时的输出名称归类，并可按 BMS UUID 区分同名车辆。模块保留可选车辆身份/名称接入；历史记录兼容旧版 vehicleID、bmsID 和仅含抽样电压的结构。上游已有的蓝牙与视频叠加实现保持原样。

## 验证

`bash Tools/test_bms.sh` 执行独立 ANT 解析、卡片、统计和记录测试，不依赖 UIKit 或真实蓝牙设备。完整核心测试及 generic iOS arm64 Release 编译在独立验证分支执行；本功能 PR 不新增 CI 工作流，不运行 iOS 模拟器。

测试覆盖瞬时压降与区间极值、趋势上限、断线/重复/过期帧、CSV、旧记录兼容、记录覆盖与数量上限、删除、设备/车辆筛选、活动状态以及本地日期边界。真实 BLE 读取和仪表显示需在设备上验证；这些既有连接/叠加代码没有被本次记录功能替换。
