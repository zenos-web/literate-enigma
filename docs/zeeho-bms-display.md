# 极核仪表 BMS 显示修复

BMS 图像现在同时传给九号、极核 5 寸（SE+ / AE2 Pro）和独立的极核 6.2 寸输出。启动前缓存的卡片会在会话开始前应用，后续读数、位置、字号、背景和关闭操作经过输出队列处理。

极核 5 寸按仪表协商尺寸合成卡片。原码流直传不能加入手机端生成的 BMS 图像，因此存在卡片时改为兼容转码，并请求关键帧；运行中打开卡片也能退出直传循环进入转码，首个编码帧为关键帧。关闭卡片会移除叠加，本次会话继续转码，下次连接再按保存的发送方式选择。用户保存的直传选项不被覆盖。

极核 6.2 寸在原缩放入口前增加可选卡片画布；没有卡片时仍执行原来的缩放。`Tools/verify_legacy62.py` 仅剥离四处精确的渲染接入代码后核对原始哈希，原始快照和哈希不变，控制协议、端口、协商、编码参数和发送时序继续按原版验证。

`Tools/test_ninebot_canvas.sh` 原生 macOS 验证四角/三种字号、800×480 / 1600×770 / 1024×480 / 480×800 画布、真实 H.264 编解码后卡片更新及清除；没有使用 iOS 模拟器。极核输出的原有协议/协商回归继续运行。`Tools/test_zeeho_bms.sh` 使用生产 ZeehoOutput 与真实编解码器，仅替换仪表传输，验证直传会话中打开卡片、静止源画面更新/移动/关闭、启动前卡片和 AE2 竖屏。真实仪表出画、切换兼容性以及锁屏行为仍需实车核验，转码会增加手机处理负载。
