# 极核 AE4i Pro+ 6.2 寸适配

来源：Issue #68，F31C-73BD/CarWithin 的 zeeho-ae4i-2048 分支，c9dc8e2d124480a744df165ec251c00d4005bbf1。贡献者报告实车可用；整合包尚待复测。

独立 profile 接受 1024–2048 × 480–1080 的偶数横屏尺寸，首选 2048×968。该尺寸来自仪表握手，不据此判定面板物理分辨率。菜单放在极核 AE2 Pro 下方，持久化编号追加为 26，原有 0–25 保持不变。

使用通用极核连接和编码器；原有 6.2 寸仍使用 Zeeho62Legacy。默认 25 FPS、Baseline，自动码率按帧率基础码率的 6 倍计算，最高 24 Mbps；可手动选择 12/15/18/24/30 Mbps。高帧率与高码率需按手机及仪表稳定性选择。

整合保留 BMS 叠加。高质量编码选项仅在此 profile 启用。Fork 的独立版本号及发布流程不带入；开发版本保持 App/Info.plist 当前值。

测试修正了 2046×968 的断言：它符合偶数横屏范围，应被接受；2047×968 应拒绝。
